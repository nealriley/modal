# Documentation Hub

This hub centralizes every decision, action, and research artifact for the multi-device voice capture and transcription system. Each section includes a living README and space for detailed notes.

## Quick Links
- [Decisions](decisions/README.md) — architectural choices, ADRs, trade-offs
- [Actions & Tasks](actions/README.md) — running task list, retros, follow-ups
- [Context](context/README.md) — stakeholder notes, device priorities, goals
- [Research](research/README.md) — market scans, benchmarks, competitive analysis
- [Architecture](architecture/README.md) — diagrams, flows, backend/API plans
- [Onboarding](onboarding/README.md) — how new collaborators ramp up (includes [iOS Shortcut setup](onboarding/ios-shortcut.md))
- [Worklog](worklog/README.md) — dated notes, meeting minutes, daily syncs

## How to Use
1. Start every new investigation by logging intent in **Actions** and linking to supporting context/research.
2. Capture irreversible or high-impact decisions in **Decisions** with rationale and alternatives considered.
3. Reference **Onboarding** for setup commands, repo conventions, and governance (including `AGENTS.md`).
4. Keep **Worklog** updated with short entries so future contributors can follow project momentum.
5. Mirror significant documentation into PR descriptions to keep code and knowledge synchronized.

> Tip: prefer smaller files grouped by topic rather than monolithic documents—link them here for discoverability.
