# Actions & Task Log

Use this space to track active efforts, experiments, and follow-up items. Each entry should include:

- **Owner** (person or agent responsible)
- **Intent** (what outcome we expect)
- **Status** (planned / in progress / blocked / done)
- **Links** to related PRs, research, or meeting notes

Suggested table schema:

| Date | Owner | Task | Status | Links |
| ---- | ----- | ---- | ------ | ----- |
| 2025-01-01 | Core Team | Example task | Planned | [Context](../context/README.md) |

Archive completed tasks weekly to keep the log scannable and tag blockers that need decisions.
