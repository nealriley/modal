# Architecture Notes

Use this directory for diagrams, sequence flows, API contracts, and deployment notes for the transcription + clipboard delivery platform.

Recommended structure:
- `vision.md` — north-star diagrams and capability map
- `backend.md` — API endpoints, models, scaling and security considerations
- `clients/` (optional) — per-platform integration flowcharts
- `clipboard.md` — OS-specific clipboard and automation strategies

Tools: Excalidraw, Mermaid (via markdown), or screenshots exported to `/media`.
