# Decision Records

Log significant technical or product decisions using a lightweight ADR template:

```
## ADR 000: Title
- **Date:** 2025-01-01
- **Status:** Proposed | Approved | Superseded (link to new ADR)
- **Context:** why we needed a decision
- **Decision:** what we chose and any guardrails
- **Consequences:** positive/negative outcomes, follow-up actions
```

Store each ADR as its own markdown file inside this folder (`adr-000-title.md`) and link it back here and in PRs.
