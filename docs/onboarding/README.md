# Onboarding Guide

Give new contributors a 15-minute path to productivity.

## Checklist
- [ ] Read `INIT.md` to understand product vision
- [ ] Review repo structure in `README.md`
- [ ] Configure Codespaces / local dev (see setup below)
- [ ] Understand collaboration rules in `AGENTS.md`

## Environment Setup (Codespaces)
1. Start the Codespace from the default branch.
2. Install dependencies as they are added (backend/client specific instructions will live alongside code).
3. Use the documentation hub to learn context before editing code.

## Communication Norms
- Capture decisions in `docs/decisions`
- Log daily work in `docs/worklog`
- Keep action items current in `docs/actions`

Add platform-specific onboarding docs (Android, iOS, etc.) as sub-files once implementations begin.
